# 官方规则核验

核验：2026-10-22。入口：[赛事官网](https://www.oschina.net/oa2026/)。网页是 SPA，正文检索与官网 JS、其实际使用的公开内容 API 交叉核验；浏览器自动化多次超时，未读取或提交报名个人数据。

| 项目 | 已核实内容及判断 |
| --- | --- |
| 赛道一 | 接受以开源软件解决行业问题的方案，包含 AI 工具与行业平台；技术栈不限。ChemVision 按教育行业工具申报较合适 |
| 主体 | 官方指南配置要求单位申报，明确排除个人；高校实验室、科研机构、社区等在范围内。表单候选包含“学生团队”，不能据此推翻主体要求 |
| 团队 | 上限 8 人，指定 1 名负责人；同一主体可申报不同项目/赛道 |
| 已有项目 | 评审文案对已有社区项目有专门评价口径，支持已有项目方向；未找到限定新建时间、重复参赛、既往获奖或增量比例的独立规则。不能据此承诺所有历史项目必然合格，须向会务确认 |
| 开源 | 评价包含项目协议和依赖合规；未查到强制 MIT/Apache 或要求自研/开放模型权重的具体条款。当前补全 MIT 是沿用仓库既有选择 |
| 材料 | 可运行代码仓库、作品说明（建议 PDF）、展示核心流程的视频链接；报名后按确认邮件提交 |
| 截止 | 2026-10-31 24:00 北京时间，即 11-01 00:00（UTC 10-31 16:00）。官网公开日程 API 的 `end_at` 与此一致 |
| 评分 | 技术创新 30%、场景落地 30%、开源治理 20%、长期发展 20%，已交叉确认 |
| 视频 | 赛道一未找到明确时长；本包约三分钟仅为制作建议。3—5 分钟成片是赛道三要求，不能套用 |
| 决赛 | 面向入围者的线下路演；官网前端显示 11-13，内容 API 留有 11-13—14、14 日路演信息，且前端主动覆写旧日期。须以入围通知确认最终安排 |
| 邮件 | 前端正文给出 `bjoscc@oschina.cn` 并要求截止前发送打包材料；公开配置仍写收件说明随报名确认邮件通知。最终以报名确认邮件为准，本轮未发邮件 |
