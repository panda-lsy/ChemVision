# 创新性与同类能力比较

比较日期：2026-10-22。目的为界定功能组合与自研边界，不做未经实验的速度、精度或教学效果排名。

| 对象 | 公开能力/边界 | ChemVision 的实际关系与差异 |
| --- | --- | --- |
| [Ketcher 官方项目](https://github.com/epam/ketcher) | 开源化学结构编辑器，支持结构/反应编辑等 | ChemVision 内嵌它并做中文/主题/Flutter 桥接；编辑算法不能列作本项目原创。差异在名称解析、学习记录和讲解流程的衔接 |
| [SmilesDrawer 官方项目](https://github.com/reymond-group/smilesDrawer) | SMILES 解析与绘制组件 | ChemVision 使用该组件渲染，图形算法与性能属于第三方；本项目负责前后流程整合 |
| [DECIMER 官方项目](https://github.com/Kohulan/DECIMER-Image_Transformer) | 化学结构图片转 SMILES 的模型与工具 | ChemVision 提供 HTTP 包装/调用、轻量结果检查和候选查询；不声称自研 OCR/识别模型 |
| 通用 AI 对话助手（功能类别） | 可对自然语言给出回答；具体产品是否支持绘图/工具不断变化 | 仅比较本项目能检查的流程：在结果页传递选定 SMILES、可编辑结构、预设工具步骤、查询记录与学情汇总。不笼统宣称所有通用助手“不能画化学” |
| 单一数据库/名称解析器（能力类别） | 名称/结构查询或化学名称解析 | ChemVision 在同一 UI 中结合中文规范化、结构编辑和教学上下文；返回的化学事实仍依赖上游与人工核验 |

## 能作为参赛差异的内容

1. SMILES 将语言模型输入输出与可编辑结构解耦，允许围绕精确结构继续讲解。
2. 固定流程与工具槽位使数据传递、失败和降级可观察，可通过工具桩测试复现。
3. 领域约束在缓存和输入检查中落地；例如反向 SMILES 缓存保留芳香原子大小写。
4. 本地学习行为与模型上下文衔接，同时明确启发式画像和真实答题的区别。

这些是工程整合特色，不能直接推导“技术独创”“全面优于其他产品”。尚无同输入、同模型、同网络环境下的竞品对照实验；未做原创性检索或专利检索，也没有化学准确率/教师学习收益结论。

若后续做对照：固定 10 个公开化合物和 5 个错误输入，先定义指标（结构可编辑性、来源可追溯性、流程步骤、错误率、耗时），记录版本与配置；保留失败样本，不能仅选择成功展示。商业产品对比需先取得合法试用条件及公开可引用资料。
