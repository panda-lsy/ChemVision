## 其他保留问题

- 反向结果 `isValid` 仍只在语法与服务边界内使用，不能表示规范化学结论；固定 confidence 值不能当校准概率。
- 主结果模型没有完整保留结构来源字段，日志可核对上游，来源在 UI 的持久化展示尚需完善。
- 知识点为子串规则，反应结果无强守恒验证；不能宣传专业化学算法创新。
- API Key 仍为明文设置；端侧推理和 ASR 未在设备上验证；Android 调试签名未改。
- Supabase 仅审阅代码，真实部署、权限/并发配额和第三方服务可用性仍待验证。没有访问真实用户目录。
- CI 文件未推送，因此没有声称远端 CI 运行通过或分支保护已生效。
- 九类材料已形成草稿，真实视频与正式 PPT 不存在；正式 PDF 需在权利、主体和演示补齐后重新导出审阅。
