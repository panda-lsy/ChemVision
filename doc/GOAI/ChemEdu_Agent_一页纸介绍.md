# ChemEdu Agent — 参赛一页纸

> **GOAI 世界人工智能开源大赛 · 无界应用赛道 · AI+教育**
> 面向个性化学习与教学辅助的教育 Agent(专注化学领域)

---

## 一、项目概述

**ChemEdu Agent** 是一款内嵌于 Flutter 移动应用的化学教育智能体,基于化学知识图谱与大语言模型,为中学和大学化学学习者提供"作业辅导 → 学情诊断 → 个性化学习规划"的完整闭环。

**核心定位**:不替代教师,而是作为学生身边"循循善诱的化学辅导老师",通过分步启发而非直接给答案的方式帮助理解知识点,并通过持续记录学习行为形成个性化画像。

---

## 二、Agent 能力闭环

对应赛题"任务理解 → 多轮交互 → 任务规划 → 工具调用 → 知识增强 → 上下文管理 → 结果交付"七环节:

| 任务类型 | 触发方式 | 工具链路 | 教育价值 |
|---------|---------|---------|---------|
| **作业辅导** | 拍照 | OCSR → PubChem → 知识图谱 → LLM | 分步启发,不直接给答案 |
| **化合物讲解** | 输入名称/SMILES | PubChem → 知识图谱 → LLM | 关联教材章节 |
| **学情诊断** | 自然语言 | 学情画像 → 知识图谱 → LLM | 识别薄弱点 + 改进建议 |
| **学习规划** | 自然语言 | 学情画像 → 知识图谱 → LLM | 生成个性化学习路径 |
| **同类题训练** | 自然语言 | 知识图谱 → LLM | 基于官能团出题 |
| **错因分析** | 拍照 | OCSR → 知识图谱 → LLM | 定位错误官能团 |
| **自由对话** | 自然语言 | LLM | 学习陪伴 |

## 三、技术架构

```
┌─────────────────────────────────────────────────────────┐
│  Flutter 移动应用(Android/iOS/Web)                      │
│  ┌───────────────────────────────────────────────────┐  │
│  │  UI 层:Agent 对话主界面 / 学情画像雷达图 / 设置页 │  │
│  └───────────────────────────────────────────────────┘  │
│  ┌───────────────────────────────────────────────────┐  │
│  │  Agent 编排层                                      │  │
│  │  TaskPlanner → AgentOrchestrator → ToolRegistry    │  │
│  │  AgentContext(@slot.field 数据传递)                 │  │
│  └───────────────────────────────────────────────────┘  │
│  ┌───────────────────────────────────────────────────┐  │
│  │  工具层                                             │  │
│  │  OcsrTool │ PubChemTool │ KnowledgeBaseTool │ LlmTool│
│  └───────────────────────────────────────────────────┘  │
│  ┌───────────────────────────────────────────────────┐  │
│  │  数据层(Hive 本地存储)                             │  │
│  │  LearningRecord → LearningProfile → 知识掌握度      │  │
│  └───────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
            │                          │
            ▼                          ▼
    Cloudflare Worker 代理        大语言模型 API
    (OCSR / PubChem 中转)        (BlueLM / 自部署)
```

**关键设计**:
- **Flutter 内嵌 Agent 逻辑**:无需独立后端,降低复赛部署门槛
- **化学知识图谱**:31 个预置知识点(有机/无机/物理化学),覆盖中学+大学,基于官能团 SMILES 模式匹配
- **学习记录闭环**:扫描/练习行为自动写入 Hive,反馈到学情画像,形成"扫描→记录→画像→诊断→规划"完整链路
- **提示词工程**:7 套教育专用提示词模板,作业辅导严格遵循"不直接给答案"的教育伦理

---

## 四、创新亮点

1. **教育伦理优先**:作业辅导采用分步启发式 Prompt,引导思考而非代答
2. **混合知识库**:预置知识图谱 + PubChem API + LLM 三层增强,兼顾准确性与覆盖面
3. **学情画像可视化**:自绘雷达图展示 5 大化学分类掌握度,直观识别薄弱区
4. **本地优先合规**:学习数据全部本地 Hive 存储,未成年人保护设计
5. **安全边界**:Agent 结果附"安全提示",AI 生成内容明确标注风险

---

## 五、数据合规

- ✅ 学习记录、画像、收藏全部存储本地 Hive,不主动上传
- ✅ 仅 OCSR/LLM 调用时传输 SMILES/文本(可换本地模型)
- ✅ 不收集个人身份信息,不进行用户画像分析
- ✅ 用户可随时一键清除全部数据
- ✅ 符合《个人信息保护法》《未成年人保护法》对教育类应用的基本要求
- ✅ Agent 首次使用展示须知弹窗,明确 AI 生成内容风险
